## Notes

- Duration is **always stored as `durationMin: number` integer**; never store hours. All UI input flows go through `parseDuration(h, m)`
- All date strings in Entry are local `YYYY-MM-DD` (not ISO datetime). Use date-fns `format(date, 'yyyy-MM-dd')` everywhere — never `toISOString().slice(0,10)` (timezone trap)
- The `syncQueue` table is created here even though sync manager itself lands in S10 — schema must exist from the start to avoid Dexie version migrations
- `formatDate` and `formatDuration` are the **only sanctioned formatters** — UI code must never inline date or duration strings (catch via ESLint rule if practical, otherwise via code review)
- `[cardId+date]` compound index enables fast lookups for "all entries for card X in date range"; entries on the same day for the same card ARE permitted (multiple sessions)
