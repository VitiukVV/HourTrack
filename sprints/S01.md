## Acceptance Criteria

- [ ] `pnpm install` succeeds from clean checkout
- [ ] `pnpm dev` from `apps/web` opens app at http://localhost:5173
- [ ] App displays "HourTrack" title + locale-switched nav labels in uk/en/es
- [ ] All five routes render placeholder pages without errors
- [ ] PWA manifest validates; service worker registers in production build
- [ ] App installs as PWA on mobile/desktop (Add to Home Screen works)
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` pass at repo root via Turbo
- [ ] Husky pre-commit hook fires on staged TS/TSX files
- [ ] GitHub Actions CI workflow runs green on PR to main
- [ ] No backend workspace exists; only `apps/web`, `packages/shared-types`, `packages/shared-utils` placeholders

## Notes

- This sprint creates the empty workspace shells `packages/shared-types` and `packages/shared-utils`; their content is filled in S02
- Use **Variant B architecture** per §3 — pure PWA, no Supabase / no NestJS workspace. Do NOT add any backend folder
- Locale JSON files MUST share the exact same key set across uk/en/es; missing keys break i18n fallback. Add a tiny script `pnpm i18n:check` (or a vitest check) that asserts key parity
- Vercel default domain is the target; no custom domain config needed
- Service worker should not aggressively cache `data.json` from Drive — that path goes through SyncManager (S10), not Workbox runtime caching
