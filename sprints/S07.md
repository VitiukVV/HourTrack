## Acceptance Criteria

- [ ] Reports page defaults to Month period anchored on today with all non-archived cards selected
- [ ] Switching Period to Day/Week/Month/Custom updates the data and chart axis
- [ ] Custom period accepts arbitrary start/end via two date pickers; serves as the "Year" preset by selecting Jan 1 → Dec 31
- [ ] Card multi-select filters charts and table
- [ ] `Show archived` toggle includes archived cards in the multi-select pool
- [ ] Days without activity are not plotted in the bar chart (req #12)
- [ ] Top metrics show total time as `{H}H {M}M` and total earnings as `X.XX EUR`
- [ ] Bar chart bars are stacked and colored by card.color
- [ ] Pie chart labels use card name + EUR amount
- [ ] Table row earnings include custom-payment overrides
- [ ] Fixed-rate card earnings distributed proportionally to hours per entry (matches `earningsForEntry`)
- [ ] CSV export downloads UTF-8 BOM file with all entries in the current filter
- [ ] CSV note column properly escapes commas, quotes, newlines
- [ ] All strings localized in uk/en/es

## Notes

- Per req #26, fixed-rate proportional distribution lives entirely in `earningsForEntry` (S02) — Reports just calls it; no duplicate math here
- "Year" preset is intentionally not a separate button (req #3 + locked decisions) — Custom range covers it
- Recharts axis labels for dates use `DD.MM` (short) since long format is too wide; tooltip uses full `DD.MM.YYYY`
- CSV uses comma separator; for locale-safe Excel opening, the BOM `﻿` prefix is essential
- The empty-state should appear when filters yield zero entries — distinct from "no cards exist" empty state
- Currency is EUR-only (req #8, locked decision) — do NOT introduce a currency selector
