# HourTrack

Personal PWA for tracking work hours -- Google-only auth, Google Drive sync,
Google Calendar integration. Trilingual (uk / en / es).

> **Status:** Phase 0 scaffolding (S01). Active development -- not yet usable as a real app.
> Single source of truth: [`docs/PROJECT_PLAN.md`](./docs/PROJECT_PLAN.md).

## Stack

- React 19 + Vite 6 + TypeScript 5
- Tailwind CSS 4 + shadcn/ui (new-york style, neutral base)
- React Router v7
- i18next + react-i18next + browser language detector
- vite-plugin-pwa (Workbox)
- pnpm 10 workspaces + Turbo 2
- ESLint 9 (flat config) + Prettier 3 + Husky + lint-staged
- Vitest + React Testing Library + happy-dom

## Quickstart

Requirements: Node `>=22`, pnpm `>=10`.

```bash
pnpm install
pnpm dev          # starts apps/web at http://localhost:5173 via Turbo
```

Alternative direct invocation:

```bash
pnpm --filter @hourtrack/web dev
```

## Useful scripts

| Command                  | Purpose                                            |
| ------------------------ | -------------------------------------------------- |
| `pnpm dev`               | Run all dev pipelines (currently only `apps/web`). |
| `pnpm build`             | Turbo build across all packages.                   |
| `pnpm lint`              | ESLint flat-config across the workspace.           |
| `pnpm typecheck`         | TS strict typecheck across the workspace.          |
| `pnpm test`              | Vitest run across the workspace.                   |
| `pnpm format`            | Prettier write.                                    |
| `pnpm i18n:check`        | Asserts uk/en/es locale keys are aligned.          |
| `pnpm icons:placeholder` | Regenerates placeholder PWA PNG icons offline.     |

## i18n

Three locales: `uk` (default), `en` (fallback), `es`. Locale files live in
`apps/web/src/locales/`. The repo enforces key parity via `pnpm i18n:check`
(also wired into CI). Add a key to all three files together; missing keys break
the i18n fallback chain.

## PWA assets

Placeholder PNG icons are generated by `pnpm icons:placeholder` (used by CI
and offline dev). Branded artwork is produced via
[`pwa-asset-generator`](https://github.com/onderceylan/pwa-asset-generator) --
see [`apps/web/public/icons/README.md`](./apps/web/public/icons/README.md).
Per the project plan, branding is a low-priority pre-launch task (S14).
